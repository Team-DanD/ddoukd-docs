# 인터뷰 공통 질문지

인터뷰 1의 "남은 확인" 항목을 공통 질문으로 승격. 새 인터뷰는 `NN-샵이름.md`로 기록.

## 현재 운영

- [ ] 지금 뭘로 회원/예약 관리하나? (툴 이름까지 — PC 앱인지 모바일인지)
- [ ] 그 툴에 월 얼마 내나? 문자비 등 별도 비용은?
- [ ] 엑셀/수기 병행하나? 한다면 무엇을, 왜 툴 밖에서 하나?
- [ ] 수업 형태(1:1/그룹 혼합)와 회원권 종류(기간제/횟수제/혼합)는?
- [ ] 예약 접수는 어떤 채널로? (카톡 개별 연락 여부)

## 사용 맥락 (화면 설계의 근거)

2026-10-05에 운영자 화면의 디자인 톤을 정하면서 "사장이 수업 사이에 폰으로 자주, 짧게 쓴다"고 **추정**했다
([../design-system/README.md](../design-system/README.md), [../decisions.md](../decisions.md)). 인터뷰 1에서 확인한 건
"PC 앱이라 안 쓴다"와 "폰으로 메모·사진을 남기고 싶다"까지다. 확인되지 않은 것은 언제, 얼마나 자주, 얼마나 짧게 쓰는지다.

**실제 있었던 일을 먼저 듣는다.** "필요하세요?"라고 묻지 않는다. 필요하다는 답만으로는 범위를 검증했다고 적지 않는다.
괄호 안의 예시는 답이 막힐 때만 꺼낸다.

- [ ] 가장 최근에 예약 한 건을 받은 때부터 기록을 마칠 때까지를 순서대로 말해주세요. (어디서, 무슨 기기로, 얼마나 걸렸는지는 이어서 묻는다)
- [ ] 그 기록은 **언제** 했나요? 평소에도 그런가요? (받은 직후 / 수업 사이 / 수업 끝나고 / 퇴근 후 몰아서)
- [ ] 어제 하루 동안 관리 도구나 장부를 **몇 번** 열었나요? 한 번 열면 얼마나 봤나요?
- [ ] (카톡으로 예약을 받는 경우에만) 받은 내용을 어디에 어떻게 옮겨 적나요? 빠뜨리거나 틀린 적이 있나요?
- [ ] 최근에 관리 도구나 장부를 열었을 때, 무엇을 확인하려고 했고 실제로 어떤 화면부터 봤나요?
- [ ] 최근 예약 등록이나 변경은 **누가** 했나요? 다른 선생님의 일정이나 회원 정보를 확인해야 했던 적이 있나요? 서로 보이면 곤란한 정보도 있나요?
- [ ] 최근에 쓰기 시작한 업무용 도구는 처음에 어떻게 열었고, 그 뒤로는 어떻게 다시 들어가나요? 설치나 링크로 여는 과정에서 막힌 적이 있나요?
- [ ] 최근 회원에게 수업 일정을 알려준 일을 말해주세요. 무엇을 보냈고, 회원이 다시 물어본 것은 무엇이었나요?
- [ ] 지금 회원에게 보내는 일정이나 안내물에는 샵을 알아볼 표시(이름, 로고)가 어떻게 들어가나요? 다른 샵과 헷갈리거나 표시를 바꿔야 했던 적이 있나요?

위 사례를 들은 뒤에만 보조로 묻는다.

- [ ] (보조) 폰에 앱을 설치해서 쓰는 것과 링크로 여는 것 중 어느 쪽을 실제로 더 쓰나요?
- [ ] (보조) 회원이 수업 일정을 직접 볼 수 있는 화면이 있다면 지금 하는 일 중 무엇이 줄어드나요?

## 페인 검증

- [ ] **"샵 규정 중에 지금 쓰는 툴이 못 담아서 수기나 머릿속으로 관리하는 게 뭐예요?"**

- [ ] 노쇼/당일취소는 어떻게 관리하나? 패널티 규정 있나?
- [ ] 회원별 메모/기록은 남기나? 어디에?

## 전환 의향 (가설 검증)

- [ ] "설정만으로 우리 샵 방식대로 되는 툴"이면 갈아탈 의향? 월 얼마까지?
- [ ] (LLM 데모/설명 후) "OO 회원 노쇼 몇 번?" 같은 자연어 조회 반응 — 이것 때문에 돈 더 낼까?
- [ ] 폰에서 다 되면 (PC 없이) 그 자체가 전환 이유가 되나?
