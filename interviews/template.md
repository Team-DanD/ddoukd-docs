# 인터뷰 공통 질문지

인터뷰 1의 "남은 확인" 항목을 공통 질문으로 승격. 새 인터뷰는 `NN-샵이름.md`로 기록.

## 현재 운영

- [ ] 지금 뭘로 회원/예약 관리하나? (툴 이름까지 — PC 앱인지 모바일인지)
- [ ] 그 툴에 월 얼마 내나? 문자비 등 별도 비용은?
- [ ] 엑셀/수기 병행하나? 한다면 무엇을, 왜 툴 밖에서 하나?
- [ ] 수업 형태(1:1/그룹 혼합)와 회원권 종류(기간제/횟수제/혼합)는?
- [ ] 예약 접수는 어떤 채널로? (카톡 개별 연락 여부)

## 사용 맥락 (화면 설계의 근거)

2026-10-05에 운영자 화면의 디자인 톤을 "사장이 수업 사이에 폰으로 쓴다"는 **추정**에 기대어 정했다
([../design-system/README.md](../design-system/README.md), [../decisions.md](../decisions.md)). 인터뷰 1에서 확인한 건
"PC 앱이라 안 쓴다"까지다. 아래로 그 추정을 확인한다.

- [ ] 회원·예약 기록을 **언제** 하나? (예약 받은 직후 / 수업 사이 / 수업 끝나고 / 퇴근 후 몰아서)
- [ ] **어디서, 무슨 기기로** 하나? (샵에서 폰 / 집에서 PC / 이동 중) — 지금 툴을 여는 기기도 같이
- [ ] 하루에 **몇 번쯤** 여나? 한 번 열면 얼마나 오래 보나?
- [ ] 카톡으로 예약을 받으면 그 내용을 **어디에 어떻게 옮겨 적나**? 옮기는 데 걸리는 시간과 빠뜨리는 경우
- [ ] 화면을 열었을 때 **맨 먼저 보고 싶은 것**은? (오늘 예약 / 특정 회원의 잔여 횟수 / 만료 임박 회원 / 기타)
- [ ] 선생님이 여러 명이면 **누가** 기록하나? 선생님마다 자기 것만 보면 되나, 사장은 전체를 보나?
- [ ] 앱을 **설치**하는 것과 링크(URL)로 여는 것 중 어느 쪽이 편한가? 설치를 꺼리는 이유가 있나?
- [ ] 회원에게 **수업 일정을 보여주는 화면**(공개 캘린더)이 필요한가? 지금은 일정을 어떻게 알리나?
- [ ] 회원이 보는 화면에 **우리 샵 로고나 색**이 들어가야 하나?

## 페인 검증

- [ ] **"샵 규정 중에 지금 쓰는 툴이 못 담아서 수기나 머릿속으로 관리하는 게 뭐예요?"**
      — 답변 목록이 곧 커스텀 항목 우선순위표 ([../spec/custom-spec.md](../spec/custom-spec.md))
- [ ] 횟수 차감은 누가 어떻게 하나?
- [ ] 노쇼/당일취소는 어떻게 관리하나? 패널티 규정 있나?
- [ ] 회원별 메모/기록은 남기나? 어디에?

## 전환 의향 (가설 검증)

- [ ] "설정만으로 우리 샵 방식대로 되는 툴"이면 갈아탈 의향? 월 얼마까지?
- [ ] (LLM 데모/설명 후) "OO 회원 노쇼 몇 번?" 같은 자연어 조회 반응 — 이것 때문에 돈 더 낼까?
- [ ] 폰에서 다 되면 (PC 없이) 그 자체가 전환 이유가 되나?
