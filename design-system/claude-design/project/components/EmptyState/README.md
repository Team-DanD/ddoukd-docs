목록이나 화면에 보여줄 것이 없을 때 왜 비었는지와 다음에 할 일을 알려주는 영역.

- 상태: 제안 (구현과 화면 검증 전)
- 화면: 운영자 폰, 공개 캘린더

## 쓰는 쪽이 정하는 것

제목, 설명, 행동 버튼 하나(선택).

## 규칙

- 처음 비어 있으면 주 버튼으로 첫 등록을 권한다. 검색 결과가 없으면 보조 버튼으로 조건을 지우게 한다.
- 목록 자리에 들어갈 때는 `dd-empty--inset`으로 테두리를 뺀다.
- 장식 그림을 넣지 않는다.
- 공개 화면에서는 샵의 내부 사정을 쓰지 않는다. 없는 샵과 비활성 샵은 같은 화면이어야 한다.
