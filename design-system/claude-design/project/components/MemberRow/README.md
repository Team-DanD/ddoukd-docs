회원 한 명을 이름, 전화번호, 회원권 잔여와 함께 보여주는 목록 행.

- 상태: 제안 (구현과 화면 검증 전)
- 화면: 운영자 폰

## 쓰는 쪽이 정하는 것

이름, 전화번호, 회원권과 잔여 횟수, 만료 정보, 행을 눌렀을 때 갈 곳.

## 규칙

- 목록은 카드가 아니라 행이다. 행 사이는 1px 구분선이고 그림자와 여백을 두지 않는다.
- 왼쪽에 이름과 전화번호, 오른쪽에 회원권과 잔여 횟수를 둔다. 숫자는 tabular-nums로 자릿수를 맞춘다.
- 만료가 임박하면 주황 글자로 "만료 D-5"를 쓴다. 만료됐으면 회색 "만료" 배지를 붙이고 잔여 글자를 회색으로 낮춘다.
- 며칠 전부터 임박으로 볼지는 정해지지 않았다.
- 불러오는 중에는 행 모양 자리 표시(`dd-row--skeleton`)를 보여준다.
- 이름 앞 이니셜 원형(`dd-avatar`)은 준비돼 있지만 기본은 쓰지 않는다.
