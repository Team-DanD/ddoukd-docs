정해진 목록에서 하나를 고르는 컨트롤. 회원권, 강사에 쓴다.

- 상태: 제안 (구현과 화면 검증 전)
- 화면: 운영자 폰 (커스텀 목록은 PC 전용)

## 쓰는 쪽이 정하는 것

옵션 목록, 선택된 값, placeholder, 상태.

## 규칙

- 폰에서는 네이티브 `select`를 쓴다. 커스텀 목록은 PC에서만 쓴다.
- 회원처럼 수가 많고 검색이 필요한 대상은 Select로 만들지 않는다. 검색 TextField와 목록을 시트에 담는다.
- 커스텀 목록은 그림자 없이 1px 테두리로 구분한다. 옵션 높이는 44px이다.
- 선택된 옵션은 굵은 글자와 보라 체크로 표시한다.
- 회원권 종류가 세 개 이하인 샵에서 버튼 묶음으로 바꿀지는 정해지지 않았다.
