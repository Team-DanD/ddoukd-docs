예약, 회원권, 수업의 상태를 알리는 배지. 정보 표시 전용이고 누를 수 없다.

- 상태: 제안 (구현과 화면 검증 전)
- 화면: 운영자 폰

## 쓰는 쪽이 정하는 것

문구와 변형. 변형은 세 가지뿐이다.

| 변형 | 모양 | 쓰는 상태 |
| --- | --- | --- |
| `dd-badge--booked` | 보라 외곽선, 보라 글자 | 예약, 공개 |
| 기본 | 회색 외곽선, 회색 글자 | 완료, 취소, 만료, 마감, 휴강, 비공개 |
| `dd-badge--no-show` | 검정 면, 흰 글자 | 노쇼 |

## 규칙

- 면을 채우는 배지는 노쇼 하나다. 사장이 반드시 봐야 하는 상태이기 때문이다.
- 회색 배지는 색이 같다. 문구로 구분한다.
- "완료"는 저장된 상태가 아니다. 예약 상태가 BOOKED이고 수업 종료 시각이 지났을 때 보여준다.
- 만료 임박은 배지가 아니라 주황 글자(`text-warn`)로 쓴다. 예: "만료 D-5".
- 높이 24px, 글자 12px 굵게. 문구는 확정 전이다.
