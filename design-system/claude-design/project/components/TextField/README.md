한 줄 값을 입력받는 필드. 이름, 전화번호, 비밀번호, 검색어, shop-key에 쓴다.

- 상태: 제안 (구현과 화면 검증 전)
- 화면: 운영자 폰

## 쓰는 쪽이 정하는 것

값과 placeholder, 상태(`dd-field--error`, `--disabled`, `--readonly`), 앞 요소(검색 아이콘 또는 고정 접두)와 뒤 요소(보기, 지우기, 복사 버튼).

## 규칙

- `dd-field`는 항상 `div`다. 라벨은 FormField가 `for`와 `id`로 연결한다. 필드를 `label`로 감싸지 않는다.
- 입력 글자는 16px이다. iOS가 16px 미만 입력에서 화면을 확대하기 때문이다.
- 테두리는 1px `border-control`이다. 이 색은 흰 면과 3:1 이상이어야 해서 구획선보다 진하다.
- 오류는 빨간 1px 테두리에 더해 아래에 아이콘과 문구를 둔다. 글자를 빨갛게 하지 않는다.
- 전화번호, 날짜 같은 숫자는 tabular-nums로 자릿수를 맞춘다.
- 뒤 요소 버튼마다 이름을 준다("비밀번호 보기", "복사"). 붙여넣기를 막지 않는다.
