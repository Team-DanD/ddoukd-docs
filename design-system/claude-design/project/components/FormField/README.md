라벨, 컨트롤, 도움말, 오류 문구를 한 가지 방식으로 묶는 폼 단위.

- 상태: 제안 (구현과 화면 검증 전)
- 화면: 운영자 폰

## 쓰는 쪽이 정하는 것

라벨 문구, 안에 넣을 컨트롤(TextField, Select 등), 도움말, 오류 문구.

## 규칙

- 라벨은 컨트롤 위 8px, 필드 사이는 20px이다.
- 선택 항목에만 "(선택)"을 붙인다. 필수에 `*`를 붙이지 않는다.
- 오류 문구는 무엇이 잘못됐고 어떻게 고치는지 쓴다.
- 시작일과 만료일처럼 한 값을 이루는 짝만 나란히 둔다(`dd-formrow`). 나머지는 한 열이다.
- 계산으로 정해지는 값(만료일)은 읽기 전용 필드로 보여준다.
- 필드에 속하지 않는 서버 오류는 폼 맨 위 오류 요약에 둔다.
- PC에서 폼 한 열의 폭은 480px까지다.
