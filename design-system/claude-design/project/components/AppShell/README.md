운영자 폰 화면을 감싸는 틀. 화면 제목, 본문, 하단 고정 바, 하단 내비게이션으로 이뤄진다.

- 상태: 제안 (구현과 화면 검증 전)
- 화면: 운영자 폰

## 쓰는 쪽이 정하는 것

화면 제목과 오른쪽 보조 정보, 하단 고정 바의 버튼, 내비게이션 항목과 현재 화면.

## 규칙

- 화면의 주 행동은 본문이 아니라 하단 고정 바에 둔다. 엄지가 닿는 자리다.
- 하위 화면(회원 등록)은 내비게이션을 숨기고 왼쪽 위에 뒤로 가기를 둔다.
- 현재 화면은 보라 글자와 굵기로 표시한다. 면을 칠하지 않는다. 라벨을 숨기지 않는다.
- 구획은 1px 선으로만 나눈다.
- 내비게이션 항목(예약, 회원, 회원권, 더보기)은 시안의 예시이며 확정되지 않았다.
- 백오피스는 이 틀을 쓰지 않는다.
