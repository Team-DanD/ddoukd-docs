사용자가 누르는 행동. 보라 면의 주요 버튼은 화면에 하나만 둔다.

- 상태: 제안 (구현과 화면 검증 전)
- 화면: 운영자 폰

## 언제 쓰나

- 기본(primary): 화면의 주 행동(회원 등록, 저장, 예약 추가). 화면 아래 고정 바에 둔다.
- `secondary`: 그만두기, 취소, 보조 행동.
- `danger`: 되돌릴 수 없는 행동(휴강 처리, 노쇼 기록). 확인창 안에서 쓴다. 색은 제안값이다.
- `disabled`: 실제로 누를 수 없을 때만.

## 쓰는 쪽이 정하는 것

문구, 변형, 폭(`dd-btn--block`이면 부모 폭 전체), 앞 아이콘, 진행 중 여부(`aria-busy="true"`).

## 규칙

- 높이는 48px 이상, 누르는 영역은 44px 이상.
- 문구는 행동 그대로 쓴다("휴강 처리"). "확인", "예"를 쓰지 않는다.
- 하단 고정 바에서는 폭 전체로 하나를 두거나, 그만두기 1 : 저장 2 비율로 나란히 둔다.
- 진행 중에는 폭을 유지한 채 스피너와 진행 문구를 넣는다.
- 필수 값이 비어 있어도 비활성으로 두지 않는다. 눌렀을 때 오류로 알려준다.
