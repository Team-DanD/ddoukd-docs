여러 건을 열로 나눠 훑어보는 표. 운영자 화면을 PC(1024px 이상)에서 볼 때 쓴다.

- 상태: 제안 (구현과 화면 검증 전)
- 화면: 운영자 PC 보기

## 쓰는 쪽이 정하는 것

열 구성, 행 데이터, 행을 눌렀을 때 갈 곳.

## 규칙

- 폰에서는 표를 가로 스크롤로 밀어 넣지 않는다. 1024px 미만에서는 MemberRow, BookingRow 목록으로 바꾼다.
- 글자는 왼쪽, 숫자는 오른쪽(`is-num`)에 맞춘다.
- 행을 누를 수 있을 때만 `dd-table--interactive`를 붙여 hover 면을 준다.
- 백오피스는 이 표를 쓰지 않는다. 팀 내부 화면은 기성 UI 라이브러리로 만든다.
