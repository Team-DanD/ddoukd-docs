화면 위에 뜨는 대화상자. 짧은 작업과, 되돌릴 수 없는 행동 직전의 확인에 쓴다.

- 상태: 제안 (구현과 화면 검증 전)
- 화면: 운영자 폰(하단 시트), PC(가운데 상자)

## 쓰는 쪽이 정하는 것

제목, 본문, 버튼 문구와 변형, 닫을 때의 동작.

## 규칙

- 그림자를 쓰지 않는다. 배경 가림막(`overlay-scrim`)과 1px 선으로 떠 있음을 표시한다.
- 제목은 행동을 그대로 묻는다. 본문에는 무엇이 바뀌고 되돌릴 수 있는지 쓴다.
- 위험한 행동의 실행 버튼은 `danger`, 그만두는 버튼은 `secondary`다. 처음 포커스는 그만두는 쪽에 둔다.
- 폰은 하단 시트(`dd-modal--sheet`)로 바꾸고 버튼을 세로로 쌓는다. 실행 버튼이 위다.
- 포커스를 안에 가두고, 닫으면 열었던 요소로 돌려준다. Esc로 닫는다. 확인창은 배경을 눌러도 닫히지 않는다.
- 노쇼 기록의 회원권 차감 문구는 예시다. 차감 정책은 이 시스템이 정하지 않는다.
