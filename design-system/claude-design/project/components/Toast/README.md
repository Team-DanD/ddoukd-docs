방금 한 행동의 결과를 짧게 알리는 알림. 화면 흐름을 막지 않는다.

- 상태: 제안 (구현과 화면 검증 전)
- 화면: 운영자 폰

## 쓰는 쪽이 정하는 것

문구, 성공 또는 실패, 행동 버튼 하나(선택).

## 규칙

- 사용자가 조치해야 하는 오류는 Toast만으로 알리지 않는다. 폼 오류나 확인창에 남긴다.
- 문구만으로 뜻이 통해야 한다("예약이 취소됐어요").
- 성공은 4초 뒤 닫힌다. 실패는 자동으로 닫지 않는다.
- 폰에서는 하단 고정 바 위에 둔다. 최대 3개까지 쌓는다.
- 그림자 없이 1px 테두리다. 성공 표시는 옅은 보라 면에 보라 체크다.
