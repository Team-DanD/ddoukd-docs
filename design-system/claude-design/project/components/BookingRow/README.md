예약 한 건을 시각, 회원, 강사와 회원권 잔여, 상태로 보여주는 목록 행.

- 상태: 제안 (구현과 화면 검증 전)
- 화면: 운영자 폰

## 쓰는 쪽이 정하는 것

시각, 회원 이름, 강사, 회원권 잔여, 상태 배지, 행의 시점(`is-past`, `is-current`).

## 규칙

- 카드가 아니라 행이다. 왼쪽 강조선과 그림자를 쓰지 않는다.
- 시각은 굵은 tabular-nums로 왼쪽에 고정한다. 지난 행의 시각은 회색으로 낮춘다.
- 지금 진행 중인 행만 옅은 보라 면(`background-current`)이고 시각이 보라다. 한 화면에 하나다.
- 진행 중인 행에서는 이번 수업으로 잔여가 어떻게 바뀌는지 "잔여 3회 → 2회"로 보여준다.
- 취소된 예약도 지우지 않고 회색 배지로 남긴다. 투명도를 낮추지 않는다.
