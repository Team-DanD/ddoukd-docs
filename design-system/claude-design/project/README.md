흰 바탕과 가는 회색 선이 장부의 칸을 만들고, 보라 하나가 지금 할 행동과 지금 보는 곳을 가리킨다. 숫자(잔여 횟수, 시각, 전화번호)가 글보다 먼저 읽히게 쓴다. 사장이 수업 사이에 폰으로 쓴다. 2026-10-05에 운영자 화면의 톤으로 확정했다. 컴포넌트는 구현과 검증 전의 제안이다.

## 무엇을 위한 시스템인가

똑디는 필라테스, PT 같은 수업형 운동샵의 예약과 회원관리 서비스다. 제품의 본체는 회원권(횟수 차감, 잔여, 만료)이고 화면의 대부분은 회원 목록, 회원권 잔여, 예약 기록 같은 장부다.

- 이 시스템은 사업장 운영자 화면을 위한 것이다. 사장과 강사가 폰으로 쓴다.
- 백오피스는 이 시스템의 컴포넌트를 쓰지 않는다. 팀 내부 PC 화면이라 기성 UI 라이브러리로 만든다. 고객이 보는 화면이 백오피스에 생기면 다시 본다.
- 공개 캘린더의 톤은 정해지지 않았다.

## 글

- 한국어로 쓰고 해요체로 말한다. "회원을 등록했어요", "아직 등록한 회원이 없어요".
- 버튼과 제목은 행동을 그대로 쓴다. "휴강 처리", "이 수업을 휴강 처리할까요?". "확인", "예 / 아니오"를 쓰지 않는다.
- 오류는 무엇이 잘못됐고 어떻게 고치는지 쓴다. "숫자만 10~11자리로 입력해주세요".
- 숫자를 먼저 보여준다. "10회권 · 잔여 3회", "만료 D-5", "잔여 3회 → 2회".
- 이모지를 쓰지 않는다.

## 색

색마다 뜻이 하나다.

- 보라(`action-primary-background`, `selection-background`, `selection-indicator`)는 지금 할 행동, 선택, 현재 위치다. 보라 면의 버튼은 화면에 하나만 둔다.
- 옅은 보라 면(`background-current`)은 지금 진행 중인 행 하나에만 쓴다.
- 검정 면은 노쇼 배지(`status-no-show-background`) 하나다.
- 회색 외곽선 배지(`status-muted-*`)는 끝났거나 닫힌 상태다. 완료, 취소, 만료는 색이 같고 문구로 구분한다.
- 주황 글자(`text-warn`)는 만료 임박 하나에만 쓴다. 면으로 쓰지 않는다.
- 빨강(`feedback-error-border`, `action-danger-border`)은 오류와 위험의 테두리, 아이콘에만 쓴다. 빨간 글자와 빨간 면을 쓰지 않는다.
- 면은 `background-canvas`(흰색)가 기본이고 보조 면은 `background-subtle` 한 단계만 쓴다.
- 글자는 `text-primary`, 설명은 `text-secondary`다. 옅은 보라 면과 비활성 면 위의 보조 글자는 `text-on-muted`를 쓴다. `text-secondary`는 그 면에서 대비가 모자란다.
- 컴포넌트에서는 `color-*` 원시 색을 직접 쓰지 않고 역할 토큰을 쓴다.
- 색만으로 뜻을 전하지 않는다. 상태에는 문구를 함께 둔다.
- 취소되거나 만료된 것도 읽을 수 있어야 한다. 투명도를 낮추지 않는다.
- 라이트 테마 하나만 있다.

## 글자

- 서체는 Noto Sans KR 하나다. 굵기는 400, 500, 700을 쓴다.
- 화면 제목은 `heading`(20px), 행의 이름과 시각은 `row-title`(15px 굵게), 보조 정보는 `row-meta`(13px)다.
- 입력 글자는 `control`(16px)이다. 16px 아래로 내리지 않는다.
- 배지와 라벨은 `label`(12px)이다. 12px 아래로 내리지 않는다.
- 시각, 잔여 횟수, 전화번호, 날짜에는 tabular-nums를 쓴다.

## 형태

- 선은 모두 1px이다. 구획은 `border-strong`, 행 구분은 `border-subtle`, 입력과 보조 버튼의 테두리는 `border-control`이다.
- `border-control`은 구획선보다 진하다. 입력 필드의 경계는 바탕과 3:1 이상이어야 하기 때문이다.
- 모서리는 버튼과 입력이 `radius-control`(8px), 배지가 `radius-badge`(4px)다. Radio, 스위치, 이니셜 원형만 `radius-signal`이다.
- 그림자를 쓰지 않는다. Modal, Toast, Select 목록 같은 떠 있는 면은 1px 선과 배경 가림막(`overlay-scrim`)으로 구분한다.
- 목록은 카드가 아니라 행이다. 행 사이에 여백을 두지 않고 선으로 나눈다.

## 간격과 크기

- 간격은 4px 기반(`space-4`부터 `space-64`)이다.
- 화면 가로 여백은 16px이다. 행의 세로 패딩은 12px, 필드 사이는 20px이다.
- 버튼과 입력 필드는 48px 이상, 누르는 영역은 44px 이상, 목록 행은 60px 이상이다.
- 기준 화면은 폰 390 × 844다. 1024px부터 목록을 표로 바꾼다.
- 화면의 주 행동은 하단 고정 바에 둔다.

## 상태와 접근성

- 포커스는 `focus-color` 2px outline을 2px 띄워 보여준다. 테두리와 따로 그린다.
- hover는 주요 버튼이 `action-primary-hover`, 그 밖은 `background-subtle`이다.
- 비활성은 `action-disabled-background` 면에 `action-disabled-foreground` 글자다.
- 본문 글자는 바탕과 4.5:1 이상, 컨트롤 테두리와 포커스 표시는 3:1 이상이다.
- 전환은 `motion-fast`(150ms), 펼침은 `motion-slow`(300ms)다. 움직임 줄이기 설정에서는 뺀다.

## 아이콘

- 아이콘은 lucide를 쓴다. 크기는 16, 20, 24px이다.
- 장식 그림을 쓰지 않는다. 이전 포스터 톤의 장식 여섯 가지는 운영자 화면에 쓰지 않는다.
- 로고는 아직 확정되지 않았다. 확정될 때까지 이름을 글자로 쓴다.

## 확정되지 않은 것

- 로고. 초안의 브랜드 색은 검정, 보라, 노랑이다. 운영자 화면에서 노랑을 뺐으므로 로고와의 연결은 보라 하나다.
- 공개 캘린더가 이 톤을 쓸지, 포스터 톤 변형을 쓸지. 샵별 로고와 색 커스텀(후순위)과 함께 정한다.
- 서체를 Pretendard로 바꿀지. 바꾸면 폰트 파일을 직접 실어야 한다.
- 회원 목록의 이니셜 원형을 기본으로 켤지.
- 만료 임박으로 보는 기준 일수.
- 회원권 선택을 Select로 할지 버튼 묶음으로 할지.
- 상태 문구(예약, 완료, 노쇼, 취소, 만료)와 내비게이션 항목(예약, 회원, 회원권, 더보기).
- 대기, 운동 강도, 그룹 수업 정원 표시는 1:1 수업 범위에 없어 뺐다. 그룹 수업을 열 때 다시 만든다.
- 다크 테마. 색을 `overlay-scrim` 등에 직접 적은 곳이 있어 추가할 때 손봐야 한다.
- 내비게이션 항목, 목록의 페이지 방식, 회원권 차감 규칙 같은 제품 정책은 이 시스템이 정하지 않는다.
