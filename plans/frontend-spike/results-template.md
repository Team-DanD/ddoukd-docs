## 4. 막힌 곳

막힌 것마다 한 줄씩 적는다.

| 무엇이 | 어디서(시나리오, 플랫폼) | 원인 | 어떻게 풀었나 | 든 비용(파일 수, 시간) | 증거(스크린샷, 로그 위치) |
| --- | --- | --- | --- | --- | --- |
| | | | | | |

"어떻게 풀었나"는 아래 중 하나로 시작한다.

- **컴포넌트 분기**: 그 컴포넌트만 `.web.tsx` 등으로 나눴다
- **화면 분기**: 화면 전체를 플랫폼별로 따로 만들었다
- **라이브러리 수정**: 가져온 컴포넌트의 내부를 고쳤다
- **못 풀었다**
