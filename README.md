## 한 줄 정의

필라테스/PT/크로스핏 같은 수업형 운동 업체를 위한 **무한정 커스텀 가능한 예약·회원관리 SaaS**.
수업 형태(1:1/1:다), 회원권 정책(기간제/횟수차감제), 강사 스케줄을 업체가 설정만으로 조합하고,
LLM 레이어로 "박서현 회원 노쇼 횟수 보여줘" 같은 자연어 조회를 지원.

제품의 본체는 **회원권 엔진**이고 예약은 그 표면. 우선순위 충돌 시 회원권 쪽이 이긴다.
